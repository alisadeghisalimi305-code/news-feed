# خوراک خبری کانال تلگرام

متن پست‌های یک کانال عمومی تلگرام را هر ۴ ساعت می‌گیرد و در یک صفحه‌ی وب فارسی (راست‌به‌چپ، تم روشن/تیره، جستجو) نمایش می‌دهد.

## راه‌اندازی (حدود ۵ دقیقه، رایگان)

1. فایل `config.json` را باز کن و `CHANNEL_NAME_HERE` را با نام کانال (بدون @) عوض کن.
2. در github.com یک مخزن (Repository) جدید بساز و همه‌ی فایل‌های این پوشه را در آن آپلود کن
   (پوشه‌ی `.github` هم باید باشد).
3. در مخزن: **Settings → Pages → Source: Deploy from a branch → Branch: main، پوشه‌ی /docs** → Save.
4. در تب **Actions** روی `update-feed` بزن و **Run workflow** را بزن تا اولین بار اجرا شود.
5. بعد از چند دقیقه، آدرس صفحه در Settings → Pages نمایش داده می‌شود. از آن به بعد خودکار هر ۴ ساعت به‌روز می‌شود.

## اجرای دستی روی کامپیوتر

```
pip install beautifulsoup4
python fetch.py
```
سپس `docs/index.html` را باز کن.

## نکته‌ها
- فقط کانال‌های عمومی (که صفحه‌ی `t.me/s/نام‌کانال` دارند) پشتیبانی می‌شوند.
- پست‌هایی که فقط عکس/ویدیو دارند و متن ندارند نادیده گرفته می‌شوند.
- تعداد پست‌های نگه‌داری‌شده با `max_posts` در `config.json` تنظیم می‌شود.
- اگر مخزن را Private کنی، Pages در پلن رایگان کار نمی‌کند؛ مخزن را Public بگذار.
